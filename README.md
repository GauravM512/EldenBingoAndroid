# Elden Bingo Android

Unofficial Android port of Elden Bingo.

Elden Bingo Android brings the Elden Ring bingo racing experience to Android devices while remaining compatible with the original Elden Bingo ecosystem.

## Features

* Join existing Elden Bingo servers
* Create and join bingo lobbies
* Player, Team, and Spectator modes
* Real-time bingo board synchronization
* Lobby chat
* Map preview support
* Administrator and referee controls
* Lockout and non-lockout game modes
* Custom bingo board support
* Modern Android UI built with Jetpack Compose

## Installation

1. Download the latest APK from the Releases page.
2. Install the APK on your Android device.
3. Connect to an Elden Bingo server.
4. Join or create a lobby and start playing.

## Compatibility

This application is designed to work with servers running the original Elden Bingo protocol.

## Technology Stack

* Kotlin
* Jetpack Compose
* Material 3
* Kotlin Coroutines
* AndroidX Libraries

## Project Status

This project is currently under active development.

Implemented features include:

* Lobby system
* Bingo board gameplay
* Chat
* Map preview
* Spectator mode
* Admin controls

Some desktop-specific functionality from the original Windows application may not yet be available on Android.
